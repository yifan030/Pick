# Pick 前端全面重设计 — 设计文档

> **日期：** 2026-06-29
> **状态：** 待评审
> **范围：** Vue 3 前端全部页面重设计

## 一、设计目标

将现有大众点评/美团风格的移动端 Web App，全面重设计为 **大地色 Zakka 极简风格**（参考小红书、无印良品），提升视觉质感和用户体验。

### 核心原则
- **少即是多** — 减少视觉噪音，大量留白
- **温润质感** — 陶土棕主色 + 暖灰米辅助 + 奶白背景
- **卡片至上** — 大图卡片，圆角 12px，极轻阴影
- **内容呼吸** — 减小信息密度，突出封面图

---

## 二、技术选型

| 项 | 现状 | 目标 |
|---|---|---|
| UI 框架 | Element Plus 2.9 | **Naive UI**（尤雨溪推荐，天生极简设计语言） |
| 样式方案 | 手写 CSS + Element 变量 | Naive UI 主题变量 + CSS 变量 |
| 暗色模式 | 无 | **不做暗色模式**（保持克制范围） |
| 图标 | @element-plus/icons-vue | Naive UI 内置图标或 @vicons/ionicons5 |
| 构建工具 | Vite 6.2 | 保持不变 |
| 状态管理 | Pinia 3.0 | 保持不变 |
| 路由 | Vue Router 4.5 | 保持不变 |

### 从 Element Plus 迁移到 Naive UI

**为什么要换？**
- Naive UI 的设计哲学就是"极简"，与目标风格吻合
- 内置更现代的默认样式：更大圆角、更轻阴影、更柔和的颜色
- Tree-shaking 更好，无需全量引入样式
- 提供 `n-config-provider` 全局主题定制，改色成本低

**迁移策略：**
1. 用 Naive UI 的 `n-config-provider` 配置全局主题色、圆角、字体
2. 逐页替换 Element Plus 组件为 Naive UI 对应组件
3. 移除 `element-plus` 依赖和 CSS 引入
4. 清理旧的 Element 专属 CSS 覆盖

## 三、配色方案

### 主题色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色（Primary） | `#C67B5C` | 按钮、图标激活、链接、强调文字 |
| 主色悬停 | `#A0523D` | 按钮 hover、渐变暗端 |
| 辅助色 | `#EDE4D8` | 标签背景、分割线、浅色底 |
| 页面背景 | `#F5F0EB` | 全局页面底色 |
| 卡片背景 | `#FFFFFF` | 卡片、弹窗、输入框背景 |
| 主文字 | `#3A322E` | 标题、正文 |
| 次文字 | `#B8A89A` | 辅助说明、占位文字 |
| 边框 | `#EDE4D8` | 卡片边框、列表分割 |

### Naive UI 主题配置

```js
// 全局主题覆盖
const themeOverrides = {
  common: {
    primaryColor: '#C67B5C',
    primaryColorHover: '#A0523D',
    primaryColorPressed: '#8B3A2B',
    borderRadius: '12px',
    fontFamily: '"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif',
  },
  Card: {
    borderRadius: '12px',
    paddingMedium: '16px',
  },
  Button: {
    borderRadiusMedium: '20px',
  }
}
```

### 圆角规范
- 大卡片 / 弹窗：**12px**
- 按钮 / 输入框 / 搜索栏：**20px**（胶囊形）
- 标签 / 徽章：**8px**
- 头像：**50%**（圆形）

### 阴影规范
- 卡片：`0 1px 3px rgba(0,0,0,0.04)` — 几乎不可见，仅做层次区分
- 悬浮按钮：`0 2px 8px rgba(198,123,92,0.3)` — 带主色的扩散阴影
- 弹窗/抽屉：`0 4px 16px rgba(0,0,0,0.08)`

## 四、导航结构

### 底部导航栏（重新设计）

| 位置 | Tab 名 | 图标 | 路由 | 功能 |
|---|---|---|---|---|
| 1 | 首页 | 🏠 House | `/index` | Banner推荐 + 分类 + 探店列表 |
| 2 | 附近 | 📍 Location | `/nearby` | 基于位置发现商家（地图+列表） |
| 3 | 发布 | + | `/blogEdit` | 探店笔记发布（中间突出按钮） |
| 4 | 订单 | 🎫 Ticket | `/orders` | 我的优惠券 + 订单列表 |
| 5 | 我的 | 👤 User | `/info` | 个人主页、设置、收藏 |

**中间发布按钮**使用渐变主色圆形按钮，带主色扩散阴影，视觉上突出。

### 导航栏样式
- 高度：约 56px
- 背景：纯白 `#FFFFFF`
- 顶部分割线：`1px solid #EDE4D8`
- 激活态：主色 `#C67B5C` 填充图标 + 文字
- 非激活：`#B8A89A` 线框图标 + 文字

**Banner 推荐区域：**
- 高度约 140px，主色渐变底（#C67B5C → #A0523D）
- 白色文字，圆角 12px
- AI 入口用半透明白底圆角按钮
- 可横向滑动切换多个 Banner

### 5.2 附近页（/nearby）— 新页面

- 上半屏为地图视图（可用 Leaflet 或简单静态地图）
- 下半屏为附近商家列表
- 列表卡片与首页探店卡片复用样式

### 5.3 商家列表（/shopList）

保持顶部排序栏结构，但视觉升级：
- 排序栏背景纯白，标签式切换替代下拉
- 卡片：左侧 80px 方形缩略图，右侧信息区
- 评分使用 Naive UI 的 `n-rate` 替代 Element 的评分组件

### 5.4 商家详情（/shopDetail/:id）

- Header 区：店铺名 + 评分 + 排名徽章
- 图片轮播：Naive UI `n-carousel`（比 Element 更现代）
- 优惠券卡片：保持左右分栏结构，圆角升级到 12px
- 评论标签：胶囊形，辅助色底

### 5.5 订单页（/orders）— 新页面

- 顶部 Tab 切换：优惠券 | 订单
- 优惠券列表：卡片式，左侧面值 + 右侧使用条件
- 订单列表：时间线式，状态标签清晰

### 5.6 我的（/info）

- 顶部个人信息卡片：头像 + 昵称 + 等级
- 功能列表：收藏、足迹、设置等
- Naive UI `n-list` + `n-cell` 实现

### 5.7 AI 导购聊天（/ai-assistant）

- 聊天界面保留独立全屏页面
- 入口来源：首页 Banner → "✨ AI 帮我推荐" 按钮 → 路由跳转
- 消息气泡：用户右侧主色底、AI 左侧白底
- 输入框：底部固定，胶囊形

### 5.8 登录/注册

- 保留手机号 + 密码登录方式
- 页面整体居中，顶部大 Logo
- 输入框胶囊形，按钮主色
- 底部协议勾选

## 八、迁移路径

1. **Phase 1：基础设施** — 安装 Naive UI，配置全局主题，替换 main.js 中的样式引入
2. **Phase 2：框架页面** — App.vue + FootBar 重写，路由结构调整（新增 /nearby、/orders）
3. **Phase 3：首页重设计** — 核心页面，Banner + 分类 + 瀑布流
4. **Phase 4：商家相关** — 商家列表 + 商家详情
5. **Phase 5：订单+用户** — 新增订单页 + 重设计个人中心
6. **Phase 6：登录+AI聊天** — 登录注册 + AI 导购聊天美化
7. **Phase 7：清理** — 移除 Element Plus 依赖，清理旧 CSS
