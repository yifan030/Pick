UI 框架选择

目前用的是 Element Plus 2.9。极简风格对组件库的设计语言要求更高，你倾向于？

A

保留 Element Plus + 深度定制

利用 CSS 变量覆盖主题色、圆角、间距。改动最小，但设计自由度受限。

工作量：⭐⭐ | 自由度：⭐⭐

B

切换到 Naive UI

尤雨溪推荐的 Vue 3 组件库，天然极简设计语言，TypeScript 优先，暗色模式内置。

工作量：⭐⭐⭐ | 自由度：⭐⭐⭐⭐

C

Tailwind CSS + Headless UI

完全自定义设计，最大自由度。适合追求独特视觉风格。无预设组件，需从头搭建。

工作量：⭐⭐⭐⭐⭐ | 自由度：⭐⭐⭐⭐⭐

D

Ant Design Vue

蚂蚁金服设计体系，成熟稳定，但偏企业级，设计风格较"重"。

工作量：⭐⭐⭐ | 自由度：⭐⭐⭐
